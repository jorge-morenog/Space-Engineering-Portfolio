# Spacecraft Mechanical Design and AIT

This section contains selected projects related to spacecraft mechanical design, equipment integration and Assembly, Integration and Testing activities.

The projects cover parametric CAD design, modular spacecraft architecture, mechanical interfaces, equipment accommodation, harness routing, connector definition, cable support strategy, harness flattening and manufacturing documentation.

The work was developed mainly using CATIA V5 and MATLAB, with emphasis on design parametrization, mechanical integration, interface definition, manufacturability and configuration adaptability.

## Projects

- Parametric Satellite Tray Design
- Modular Microsatellite Mechanical Design
- Satellite Harness Routing and Manufacturing Documentation
